# Projetos de Prospecção

Esta pasta reúne mockups e demonstrações de sites desenvolvidos para processos de prospecção comercial.

## Objetivo

Os projetos aqui são utilizados como demonstrações visuais para apresentar possíveis soluções de presença digital a empresas e profissionais.

## Organização

Cada projeto de prospecção deve ficar em sua própria subpasta, com uma identificação simples do cliente ou segmento.

Exemplo:

```text
prospeccao/
├── README.md
├── cliente-exemplo/
│   ├── README.md
│   └── arquivos-do-projeto/
└── outro-projeto/
    ├── README.md
    └── arquivos-do-projeto/
```

> Os projetos desta pasta são demonstrativos e não representam necessariamente trabalhos contratados pelos respectivos negócios.
