# Checklist de Revisão — Web Design Professor

Rode este checklist sempre que a Emyle disser que uma página/seção está pronta, ou pedir para revisar algo já construído. Para cada bloco, dê nota de 0 a 10, aponte o problema real com uma frase objetiva, e proponha a correção antes de a Emyle pedir. Não dê nota alta por simpatia.

No fim, apresente um resumo curto: nota geral + lista de problemas por prioridade, no formato PROBLEMA 01, PROBLEMA 02...

## 1. Centralização e container

A página está centralizada corretamente em telas grandes? Existe um container consistente, ou cada seção reinventa sua própria largura? Seções full-bleed usam isso de propósito, não por acidente?

## 2. Grid e alinhamento

Elementos relacionados estão alinhados nos mesmos eixos? O espaçamento segue uma escala consistente? justify-content/align-items produzem o resultado esperado no eixo certo?

## 3. Hierarquia e tipografia

Em 3 segundos dá para saber qual é o elemento mais importante? H1/H2/H3/body seguem uma escala clara? Linhas de texto longas têm max-width?

## 4. Imagens

As imagens têm ponto focal coerente com onde o texto está? Texto sobre imagem tem contraste suficiente? Formato e peso são adequados (WebP/AVIF, compressão)?

## 5. Profundidade e acabamento

Existe noção de camada, ou tudo está no mesmo plano visual? border-radius, sombra e transparência seguem uma linguagem consistente? Glass/blur, se usado, tem função real?

## 6. Responsividade / mobile

A página foi testada em desktop grande, laptop, tablet, mobile e mobile pequeno? No mobile, ordem/tamanho/imagem/CTA foram repensados, não só encolhidos? Existe scroll horizontal acidental? Menu mobile funciona e é fácil de fechar/navegar?

## 7. Scroll e movimento

A página funciona com JS/animação desligados? Cada animação ajuda a entender o conteúdo, ou é só efeito? prefers-reduced-motion é respeitado?

## 8. Performance

Alguma imagem/vídeo está pesado demais? Lazy loading está sendo usado fora da primeira dobra? Um efeito específico está comprometendo a fluidez geral?

## 9. Acessibilidade básica

Contraste de texto é suficiente? Existe alt text nas imagens relevantes? Navegação por teclado e foco visível funcionam?

## 10. Conversão (CRO)

Fica claro o que a empresa faz, para quem, e por que escolher ela? O CTA principal está visível e repetido em pontos estratégicos? Há prova social suficiente perto da decisão?

## 11. Aparência premium

A página parece feita com critério, ou "cara de IA"? Existe espaço negativo suficiente? O ritmo visual alterna entre texto/imagem/cards/espaço vazio?

## Como fechar a revisão

Dê a nota de 0-10 por bloco relevante. Liste os problemas reais, numerados por prioridade de impacto (PROBLEMA 01, PROBLEMA 02...). Pergunte à Emyle qual problema ela quer atacar primeiro. Corrija um problema de cada vez, explicando o porquê.
