# Landing Page — Emyle Andrade

Landing Page desenvolvida como projeto prático de desenvolvimento web, com foco em apresentação profissional, conversão e experiência do usuário.

O projeto foi construído utilizando **HTML, CSS e JavaScript**, sem frameworks, e publicado na Vercel.

## 🔗 Demonstração

**Site:** https://emyle-andrade-site-po3c.vercel.app/

**GitHub:** https://github.com/emyleandrade15-bit/emyle-andrade-site

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- DOM
- Responsive Design
- Vercel

## 🚀 Funcionalidades

- Navegação responsiva
- FAQ interativo com JavaScript
- Slider de depoimentos
- Contadores animados
- Animações de entrada com Intersection Observer
- Botão flutuante de contato via WhatsApp
- Layout adaptado para diferentes tamanhos de tela
- Imagens responsivas com WebP e fallback para JPEG
- Lazy loading de imagens
- SEO técnico básico
- `robots.txt`
- `sitemap.xml`
- Dados estruturados com JSON-LD
- Meta tags para compartilhamento em redes sociais

## 📁 Estrutura do projeto

- `index.html` — estrutura e conteúdo principal da página
- `fonts/` — arquivos de fontes utilizados no projeto
- `robots.txt` — configuração para mecanismos de busca
- `sitemap.xml` — mapa do site para mecanismos de busca
- arquivos de imagem e mídia utilizados na página
